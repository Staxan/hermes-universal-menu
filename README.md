# 🌐 Hermes Universal Menu

> **Универсальное меню для Telegram-агентов Hermes**  
> Постоянная клавиатура, динамические inline-меню, подключение внешних сервисов (ENOT, GitHub, Notion), модель-свитчер и автообновление через GitHub.

---

## ✨ Возможности

- **Постоянное меню (ReplyKeyboard)** — кнопки всегда под рукой, не зависят от сообщений бота.
- **Динамические inline-меню** — выбор проектов, папок, документов из внешних сервисов.
- **Поддержка сервисов из коробки**:
  - 📎 **ENOT / Yonote** — выбор документа и вставка ссылки в чат.
  - ⏏️ **ENOT** — отправка последнего сообщения в ENOT.
  - (В планах: GitHub, Notion, Obsidian).
- **Модель-свитчер** — быстрое переключение моделей на лету.
- **Управление сервисами** — добавляй/отключай сервисы прямо из Telegram.
- **Автообновление через GitHub** — установка и обновление одной командой.
